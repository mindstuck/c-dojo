# Purpose
The purpose of working through this book is to gain a foundational knowledge of C, with a focus on memory management, preprocessing, and the low-level features used when working with hardware. *Chapters 1–10* are skimmed briefly, picking out the C-specific basics that I am unfamiliar with from C#. *Chapters 11–20* are studied rigorously. *Chapters 21 onward* provide a detailed review of each standard library; they are therefore omitted, but will serve as a useful reference during development.
